# Cornell Quick Notes
**Cornell Quick Notes** is a web application designed to help users organize their notes efficiently using the Cornell Note-Taking Method. This method involves dividing a page into three sections:

1. **Cue Column:** Keywords or questions related to the main topic.
2. **Note-Taking Column:** Detailed notes and information.
3. **Summary Box:** A concise summary of the key points.

By using this app, users can easily create and manage their notes, keeping them organized and accessible. It can be a valuable tool for students, researchers, and anyone who needs to take effective notes.
